# zplinux-site

This repository contains the source code and infrastructure configuration for the `zplinux.eu`. 
The project consists of a Next.js frontend application that is statically exported and served via a Caddy web server, orchestrated using Docker Compose.

## 🏗️ Architecture

The project is structured into three main components:

*   **Client (`/client`)**: The frontend application built with [Next.js](https://nextjs.org/). It is configured to output a static site (`output: "export"`).
*   **Proxy (`/proxy`)**: A [Caddy](https://caddyserver.com/) web server that serves the static files generated by the client and handles TLS/HTTPS.
*   **Infrastructure (`/infra`)**: Docker Compose configuration to build and run the services together.

## 🚀 Getting Started

### Prerequisites

*   [Node.js](https://nodejs.org/) (for local development)
*   [Docker](https://www.docker.com/) and [Docker Compose](https://docs.docker.com/compose/) (for containerized deployment)

### Local Development

To run the Next.js application locally:

1.  Navigate to the `client` directory:
    ```bash
    cd client
    ```

2.  Install dependencies:
    ```bash
    npm install
    ```

3.  Start the development server:
    ```bash
    npm run dev
    ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Docker Compose Deployment

To build and run the entire stack (Client + Proxy) using Docker Compose:

1.  Navigate to the `infra` directory:
    ```bash
    cd infra
    ```

2.  Start the services:
    ```bash
    docker compose up --build
    ```

This will:
*   Build the `client` container, which compiles the Next.js app and exports usage artifacts to a shared volume.
*   Start the `proxy` container (Caddy), which mounts the shared volume and serves the site.

The site is configured to be available at the domains specified in `proxy/Caddyfile`.

## 📂 Project Structure

```text

├── client/          # Next.js frontend application source code
├── infra/           # Docker Compose configuration (compose.yaml)
├── proxy/           # Caddy server configuration (Caddyfile)

```

## 🛠️ Configuration Details

*   **Next.js Config**: See `client/next.config.ts`. The app is set to `output: "export"` for static site generation.
*   **Caddy**: See `proxy/Caddyfile`. It serves files from `/srv` inside the container.
*   **Networking**: The services interact via the `network_sso` docker network (configured in `infra/compose.yaml`).
